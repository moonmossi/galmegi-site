# galmegi

게임 **Galmegi(갈매기)** 홈페이지. → https://moonmossi.github.io/galmegi/

## 글 쓰는 법

**`열기.bat` 을 두 번 누르면** 브라우저에 글쓰기 창이 뜹니다.
왼쪽에 쓰면 오른쪽에 실제 사이트 모양으로 보이고, **저장**을 누르면 개발일지에 들어갑니다.

- 사진·GIF는 끌어다 놓기만 하면 크기 줄이기·WebP 변환·파일명 정리가 자동으로 됩니다
- 동영상은 유튜브에 올린 뒤 주소를 붙여넣으면 플레이어가 박힙니다
- 처음 저장할 때 폴더를 한 번 물어봅니다. **이 폴더(galmegi-site)** 를 골라주세요
- **Chrome 또는 Edge** 에서만 저장됩니다 (파이어폭스·사파리는 안 됨)

검은 명령창은 켜 둔 채로 두세요. 닫으면 미리보기가 꺼집니다.

글을 다 썼으면 GitHub Desktop 등으로 `main` 에 push → 1~2분 뒤 사이트에 반영됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 소개 |
| `devlog.html` | 개발일지 — 새 글이 맨 위에 쌓입니다 |
| `write.html` | 글쓰기 도구 (`열기.bat` 이 열어줍니다) |
| `style.css` | 사이트 공통 스타일 |
| `serve.py`, `열기.bat` | 미리보기 서버를 켜는 것 |
| `img/` | 사진 (긴 변 1600px / WebP) |

게임 소스는 이 레포가 아니라 [Murder_git](https://github.com/moonmossi/Murder_git)에 있습니다.

## 손댈 때 주의

- 사이트가 `/galmegi/` 하위 경로에 배포되므로 링크·이미지는 **전부 상대경로**로 쓸 것.
  `/style.css` 처럼 `/`로 시작하면 로컬에서는 되고 배포 후에만 깨집니다.
- 동영상 파일(mp4)은 레포에 넣지 말 것. 유튜브에 올려 링크합니다.
- 편집기로 직접 열 때는 **인코딩을 UTF-8** 로 유지할 것. 아니면 한글이 깨집니다.
